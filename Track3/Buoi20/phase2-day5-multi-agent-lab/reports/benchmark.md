## Exit ticket

**When to use multi-agent?**
Tasks with clearly distinct sub-skills (research, analysis, writing), where quality matters more than latency or cost. The decomposition allows each agent to specialise and catch mistakes in the previous stage.

**When NOT to use multi-agent?**
Simple, narrow tasks (FAQ lookup, single-step transforms) where a single LLM call suffices. The overhead in latency, token cost, and orchestration complexity is not justified when there is no specialisation benefit.
